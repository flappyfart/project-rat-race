# contributing

Useful reports include the affected component, a minimal reproduction, expected behavior, actual output and the verification performed. Never include personal credentials or live operator data.

Discuss code contributions and licensing before submitting substantial changes. Original project rights are retained in this public source release.

Changes to money movement, launch authority, isolation or checkpoint integrity need focused regression tests. A printed result is not a passing assertion. Never replace an unavailable data source with plausible-looking fabricated values.

Keep the project name Project Rat Race and the public ticker $ESCAPE. Do not prescribe an earning strategy or add activity-specific hype to the mission. Preserve source attribution and distinguish implemented mechanisms from experimental claims.
