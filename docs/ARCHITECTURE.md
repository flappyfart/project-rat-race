# architecture

## distinct components

The anatomical viewer, navigation learner, market adapter, AI workspace, accounting and signer are separate components. A visual brain is not evidence that an anatomical volume is executing software decisions.

The private operator configuration and verified chain evidence establish activation authority. HTTP requests, URL parameters, browser storage, external pages and model output cannot grant that authority.

## data flow

1. An exact configured reference asset is observed through the market adapter. The accepted raw response and normalized observation have integrity hashes.
2. A maze is generated from the observation, seed and attempt. The generated topology is checked for reachability.
3. The navigation policy updates from its outcomes. Checkpoints preserve policy state and launch identity.
4. The server verifies a complete exit route before the separate AI workspace can begin its official work.
5. The AI agent receives bounded tools, not signing keys or personal accounts. Tool results become input to later decisions.
6. Executable work must pass source-bound verification before it can become a public work preview.

## money flow

Native treasury ETH on Robinhood Chain may be converted through the approved Relay route into the same controlled wallet's Base USDC. The supported merchant payment authorizes a bounded USDC amount for AI credits.

A conversion quote is not a settled transfer. A submitted merchant payment is not a credited provider balance. Each stage is journaled, confirmed and reconciled independently.

The narrow Relay verifier is source-derived and was checked against independent official-SDK hash vectors. That is not an independent security audit.

## state and recovery

Financial journals live outside simulation reset paths. State corruption is not permission to invent a fresh budget or erase history. Ambiguous submissions are reconciled from recorded identifiers instead of blindly repeated.

The public API exposes sanitized observations. Private credentials, raw authorizations and operator data are not part of the static website.

## research inputs

The current topology uses price, daily price-change and turnover-derived proxies. The daily-change proxy is not realized volatility. Fetch time is distinguished from upstream measurement time. The software does not claim a liquidation feed, corporate-action feed or market oracle.
